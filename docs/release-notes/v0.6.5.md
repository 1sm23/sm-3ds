- MODERN controls can be remapped: jump, run, shoot and the morph ball go on any of A, B, X, Y, and the missile, X-ray and grapple on the button you choose with R held. Change them in OPTIONS -> CONTROLS -> "?" (tap a row, press the button) or in the game's CONTROLLER SETTING.
- The original controls can be remapped from the same window, and RESET puts each scheme back.
- Item messages and the help windows show the buttons you set.
- With the 3D on, things the game draws in front of Samus (some enemies) no longer hide behind her, and the message boxes in WIDE are no longer cut at the sides.
- Saving is smoother and safer: it is written in the background, whole file first, with a notice if it fails.
